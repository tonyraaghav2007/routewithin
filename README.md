# RouteWithin — Anter Prakash | Explore Yourself

High-converting, responsive web application for **RouteWithin** by Master NLP Coach **Dimple Sandhu**. Built with a radiant **Pure White & Royal Purple** authority palette, glassmorphism aesthetics, universal `rem` spacing, smooth scroll animations, and single-screen viewport fit.

## 🌟 Key Features

- **Authority Pure White & Royal Purple Design**: Built with a sleek 30% background geometric grid, frosted glassmorphism navigation bar, and high-contrast typography (`Outfit` + `Plus Jakarta Sans`).
- **Full Viewport Fit & Universal REM Spacing**: Every section is calibrated to fit cleanly within modern display heights with zero clutter or vertical bloat.
- **Interactive 16:9 Cinema Showcase**: Embedded YouTube masterclass documentary with chapters, quotes, and quick action buttons.
- **4-Pillar Alignment Architecture**: Interactive cards deconstructing the Anter Prakash methodology (Subconscious Decoupling, Linguistic Resonance, Mirror Principle, Relational Equilibrium).
- **Conversations Within Audio Player**: Embedded podcast player with speed toggle, scrub bar, live waveform, and multi-episode selector.
- **Interactive Relationship Alignment Audit**: 5-step diagnostic quiz providing instant scoring and personalized coaching pathway.
- **Upcoming Immersion & Live Countdown**: Real-time ticker and announcement banner for the Karwa Chauth Special Masterclass cohort.
- **Verified Hall of Fame Testimonials**: Category-filtered video breakthrough stories and student reviews.
- **VIP Application & Consultation Forms**: Integrated validation with simple bot-prevention captcha.
- **Smooth Scrolling Suite**: Dynamic reading progress bar, floating Back-to-Top frosted glass pill, and reveal observers.

## 🚀 Getting Started

To run locally with any static web server:

```bash
# Using npx serve or vite or python http.server
npx serve .
# or
python -m http.server 8000
```

Open `http://localhost:8000` (or `http://localhost:5173`) in your browser.
